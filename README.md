# Порядок

Личный планировщик: задачи по месяцам, сроки и отдельное пространство для мыслей. Приложение предназначено одному человеку и работает прямо в браузере.

Адрес GitHub Pages: https://antovium.github.io/planner/

## Возможности

- Быстрое добавление задачи строкой или подробной формой.
- Название, описание, три приоритета, дедлайн и месяц плана.
- Выполнение, восстановление, редактирование, перенос и удаление с подтверждением.
- Фильтры «Все», «Активные», «Выполненные», «Высокий приоритет» и поиск по названию и описанию.
- Навигация по месяцам и годам, выбор месяца и возврат к текущему.
- Месячные счетчики и процент выполнения; просроченные активные задачи видны сразу.
- Блокнот с датами создания и изменения, поиском и превращением мысли в задачу. Исходная мысль остается в блокноте.
- Цитата дня из встроенной подборки с указанием произведения и ссылкой на текст.
- Светлое, темное и системное оформление.
- Автоматическое локальное сохранение, предыдущая копия, экспорт и импорт JSON.
- Мобильная навигация, доступные формы, клавиатура и поддержка уменьшения анимации.

При новом открытии приложение выбирает текущий месяц по локальной дате устройства. Записанные задачи других месяцев сохраняются. Если вкладка остается открытой до следующего месяца и показывает текущий план, месяц сменится автоматически.

## Технологии и запуск

HTML5, CSS3 и JavaScript ES modules. Без сборки, npm-зависимостей, серверной части и сторонних ресурсов во время работы. Системные шрифты, собственные SVG-иконки.

Для локального запуска из корня проекта:

```sh
python -m http.server 8080
```

Открой http://localhost:8080/ . Простое открытие `index.html` через `file://` не подходит: браузер ограничивает загрузку JavaScript-модулей.

В GitHub Pages источник публикации: ветка `main`, каталог `/(root)`. Файл `.nojekyll` отключает обработку Jekyll. Все ссылки на ресурсы относительные; приложение работает в подкаталоге `/planner/`.

## Файлы и архитектура

| Файл | Назначение |
| --- | --- |
| `index.html` | Семантические разделы, формы, диалоги и SVG-иконки |
| `styles.css` | Адаптивная сетка, две темы, состояния и короткие анимации |
| `script.js` | Отрисовка, обработка действий, формы, часы и синхронизация вкладок |
| `core.js` | Проверка данных, локальное хранилище, даты, сортировка и статистика |
| `quotes.js` | Проверенная встроенная подборка и источники цитат |
| `favicon.svg` | Знак приложения |
| `.nojekyll` | Прямая публикация статических файлов |
| `tests/core.test.mjs` | Автоматические проверки логики и восстановления данных |
| `tests/responsive.html` | Проверка настоящего интерфейса в шести ширинах |

Интерфейс строится из одной структуры состояния. Перед изменением хранилище перечитывается, чтобы последующие действия в другой вкладке не затирали уже сохраненные записи. Открытый редактор обнаруживает, если его запись успела измениться, и оставляет введенный текст в форме. `storage`-события обновляют соседние вкладки.

Сортировка: просроченные активные, высокий приоритет, ближайший дедлайн, средний приоритет, обычные, выполненные. Для равных условий используются время создания и ID. Статистика всегда относится ко всему выбранному месяцу, независимо от фильтра и поиска.

## Хранение данных

Основной ключ: `poryadok.planner.v1`. Документ содержит `schemaVersion`, номер изменения `revision`, время изменения, задачи, мысли и настройки. В `poryadok.planner.v1.backup` хранится предыдущая валидная версия. При восстановлении поврежденный оригинал сохраняется в `poryadok.planner.v1.recovery`; его можно скачать в настройках.

JSON читается безопасно, структура и даты проверяются. Дубликаты ID исправляются с сохранением исходного документа. Поврежденный основной файл восстанавливается из доступной резервной копии. Если резервной копии нет, открывается новый план, а оригинал остается доступным. Если архивирование невозможно, приложение блокирует перезапись поврежденного файла. Данные с неизвестной более новой версией также защищены от перезаписи; будущие версии должны добавлять явные миграции в `core.js`.

Изменения считаются сохраненными после записи и проверки основного ключа. При отказе браузера или нехватке места форма сохраняет введенный текст и показывает ошибку. Перед импортом приложение проверяет весь файл и запрашивает подтверждение замены; прежний план архивируется.

Задачи и мысли не передаются на сервер. Сохранение относится к этому браузеру и адресу сайта. Очистка данных браузера удаляет локальный план; режим инкогнито обычно удаляет его при завершении сеанса. Экспорт нужен для независимой резервной копии и ручного переноса. Автоматической синхронизации между устройствами в этой версии нет.

## Цитаты

Подборка проверена по текстам произведений:

- Марк Аврелий, «Наедине с собой», перевод С. М. Роговина: книги 2, 3, 4, 5, 6, 7, 9, 10, [Викитека](https://ru.wikisource.org/wiki/Наедине_с_собой_(Марк_Аврелий;_Роговин)).
- Сенека, «Нравственные письма к Луцилию», перевод С. А. Ошерова, издание «Наука», 1977: письма 1, 3, 6, 7, 20, 33, [текст письма 1 и оглавление](https://ancientrome.ru/antlitr/t.htm?a=1346570001).
- А. С. Пушкин, «Отрывки из писем, мысли и замечания», [Русская виртуальная библиотека](https://www.rvb.ru/pushkin/01text/07criticism/01criticism/0124_30/0915.htm).

Каждая запись содержит конкретную книгу или письмо и место в тексте. В длинном перечислении обозначено сокращение. Типографские тире приведены к короткому знаку. Двадцать цитат идут по циклу: номер зависит от календарного дня, а не от случайного значения или времени перезагрузки. Новая цитата появляется после местной полуночи, в том числе в уже открытой вкладке.

## Проверки

Без установки пакетов, Node.js 22 или новее:

```sh
node --test tests/core.test.mjs
```

Проверки охватывают календарные границы и високосные годы, создание и изменение записей, сохранение после перезагрузки, несколько вкладок, ошибки чтения и записи, поврежденный JSON, резервные копии, будущую версию данных, стабильные ID, сортировку, статистику и ежедневную цитату.

Для визуальной проверки открой `/tests/responsive.html`. Страница загружает приложение в настоящем iframe с ширинами 1440, 1280, 1024, 768, 390 и 360 px, измеряет переполнение и позволяет прочитать localStorage после действий. Проверять нужно также модальные формы, длинные названия и записи, оба оформления, переходы между годами и навигацию клавиатурой.

Горячие клавиши: `N` (или `Т` в русской раскладке) открывает задачу вне полей ввода; `Ctrl/Cmd + Enter` сохраняет мысль; `Escape` закрывает диалог и возвращает фокус.

Результаты проверки опубликованной версии, 35 обязательных сценариев и измерения шести ширин приведены в [QA.md](QA.md).
